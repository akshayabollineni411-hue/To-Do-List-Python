# To-Do-List-Python

A simple To-Do List application developed using Python.

## Project Description

The To-Do List Application helps users manage their daily tasks.

Users can:
- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed

## Objectives

- To learn Python programming concepts.
- To practice lists and dictionaries.
- To use loops and conditional statements.
- To develop a simple useful application.

## Features

- Add a new task
- View all tasks
- Delete a task
- Mark a task as completed
- Simple command-line interface
- Stores task data using JSON

## Technologies Used

- Python
- JSON
